# Vytvoření bolt theme

Vytvoř bolt theme. Vzhled webu je ve složce tmp/autoluga-web. Zatim nenapojuj na bolt content, to uděláme později. Pro bolt udělej napojení na vite plugin a napoj ho na theme. Do pluginu napoj klasicky js,scss. Pokud jsou v html externi knihovny, pridej je do package a importuj v js. Do do readme dopiš jak compilaci js, scss spouštět.
